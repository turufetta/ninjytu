# 🥷 つるふぇったの手裏剣修行  
**Tsurufetta’s Shuriken Training / 츠루페타의 수리검 수행**

忍者になって手裏剣を**打つ**ブラウザゲームです。

## 遊び方

1. スタート画面で段位を選ぶ（最初は**初段のみ**）
2. 照準を合わせて「手裏剣！」で打つ
3. 的の**中央**に当てるとアイテムGET＆クリアカウント
4. 氷爆弾は手裏剣で撃ち落とす（失敗すると毒で10秒間打てない）
5. 段位クリアで次の段が解放＋ボイス再生

## 段位解放

| 段位 | クリア条件 | 解放条件 | クリアボイス |
|------|------------|----------|--------------|
| 初段 | 中央ヒット 5回 | 最初から | すごーい！おめでとう |
| 中段 | 中央ヒット 8回 | 初段クリア後 | えー！本当に強いのね |
| 上段 | 中央ヒット 12回 | 中段クリア後 | 伝説の忍者？ |

## 忍者になる（最初から再開）

スタート画面の **「忍者になる」** を**2回タップ**すると、解放状況がリセットされ初段のみから再開できます（中段・上段は🔒）。

## アイテム

- 青 👑 水の王冠 … 二刀流
- 緑 🍵 お茶 … 使用すると何かが起こる
- 赤 💣 爆弾 … 落ちてくる氷爆弾を破壊
- 黄 🌸 花 … 手裏剣増加（使用時「忍法〜花びらの舞」）

## GAME OVER

氷爆弾被弾：初段10回 / 中段8回 / 上段6回
